# LOOMIS Architecture

## Core Principles

- Fully open source software under GPLv3 License
- No opaque binary blobs
- Independently reproducible builds
- Auditable source code and dependencies
- Security without bypasses
- Minimal complexity and maintainable code

## Initial Scope

- Linux ISO booting
- GRUB2-based prototype
- x86_64 UEFI

## Future Scope

- Windows ISO support
- Additional CPU architecture
- Enterprise security features

## Current Status

Architecture reasearch and early development.
